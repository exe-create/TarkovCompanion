# Tarkov Companion — project definition

## Product
A professional personal Escape from Tarkov companion for planning raids, organizing quests and hideout progression, comparing community market data and keeping local player records.

## Vision
Provide one cohesive, readable desktop workspace with maps, screenshot-assisted tools, a floating overlay, item/recipe references, and separate game-mode profiles. Maintain fresh application source with its own reference assets. Owner-directed original tactical artwork is implemented; keep imagery readable behind the planning controls.

## Principles
- Protect user intent and existing architecture.
- Prefer the smallest correct change over patch stacking.
- Evidence, not code existence, changes verification/release status.
- Retire the old compiled tracker as directed by the owner; preserve saved progress locally.
- Prefer detached planning and manual confirmation; no game-process access or automated gameplay/transactions.
- Show community data provenance and uncertainty. Do not claim BSG approval or exact post-patch behavior without evidence.
