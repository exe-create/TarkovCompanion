# Tarkov Companion — production docs

`/AGENTS.md` is the coding-agent entry point. This folder owns current operational truth.
Update existing files in place instead of creating competing status documents.

- `PROJECT.md` — stable vision/principles
- `CURRENT_STATE.md` — what is true now / immediate goal
- `ROADMAP.md` — ordered future sequence
- `MILESTONES.md` — delivery gates
- `WORK_QUEUE.md` — active tasks
- `BUGS.md` — confirmed defects/blockers
- `DECISIONS.md` — settled decisions
- `QA_RELEASE.md` — evidence/release gates
- `RELEASE_OPERATIONS.md` — packaging/hotfix/rollback/save-compat policy
- `AI_WORKFLOW.md` — tool/agent routing
- `COLLABORATION.md` / `CREDITS.md` — external work and attribution
- `RESEARCH_AND_COMPATIBILITY.md` — versioned findings/unknowns
- `SUPPORT_AND_TRIAGE.md` — incoming report handling
- `SOURCE_REGISTRY.md` — authority map for retained project documents
